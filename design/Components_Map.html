One entry point: GitHub Actions (every 3 hours) or the Run-now button calls /api/run. A run is a chain of Vercel functions (ingest, read, draft), each with its own 300 s allowance; each hands over to the next. Gemini never starts itself: the run calls it. Every Gemini step reads its settings from Supabase.

Order: lock, news, read queue, memory check, Gemini read + score, code decides, only passes get an email lookup, Gemini drafts, Gmail + dashboard, Telegram reminder, Rohit. Reading the dashboard is public; every action that changes data needs the access code.
